# Pawn-Leaguage 2.0.2

Pawn/Pawno language support and WebAssembly compiler for Acode 1.11.7.

- `.pwn` / `.inc` syntax highlighting
- Pawn snippets/autocomplete
- Pawn compiler using `pawncc.js` + `pawncc.wasm`
- Workspace `.pawn/compile.json` auto-creation
- Compile button `▶`
- Ctrl+Shift+B compile shortcut
- Pawn-Leaguage icon
